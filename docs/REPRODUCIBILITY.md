# Воспроизводимость

## Вычислительная среда

Проверенная среда использовала Python 3.11, PyTorch 2.11, Transformers 5.15, PEFT 0.20 и CUDA 12.8. Основные запуски Qwen2.5-3B выполнялись в `bf16` с обучаемыми параметрами префикса в `fp32`.

В `requirements.txt` перечислены только прямые зависимости проекта. CUDA runtime и драйвер должны соответствовать установленной сборке PyTorch.

## Парный дизайн

Для каждого независимого запуска сравниваемые конфигурации получают один и тот же сохранённый `shared_start.pt`. В основной серии этот старт является лучшим из четырёх probe-кандидатов по validation CE. В развертке размера модели используется общий случайный старт без probe-отбора.

Такая схема отделяет различие критериев обучения от различия начальных параметров префикса.

## Разбиение EmpatheticDialogues

Датасет загружается из parquet-конвертации Hugging Face. Для классификации сохраняется первая строка каждого `conv_id`, из которой берутся `prompt` и `context`. Для генерации строки группируются по `conv_id`; целью является первая реплика участника, отличного от автора исходной ситуации.

После дедупликации доступны 17 844 / 2 763 / 2 542 эпизода для train / validation / test. Основное разбиение:

- 600 первых train-эпизодов для reward;
- следующие 6 000 эпизодов для обучения;
- первые 200 validation-эпизодов для выбора эпохи;
- первые 500 test-эпизодов для основной оценки.

Дополнительная оценка использует 2 542 классификационных эпизода и 1 000 генеративных примеров.

## Сохранение лучшей эпохи

После каждой эпохи модель генерирует ответы на чистом validation-входе. Лучший префикс сохраняется в `best_prefix.pt` по accuracy или ROUGE-L. Итоговая оценка загружает именно этот файл.

## Историческая схема padding

Завершённые серии использовали значение `0` для padding `input_ids` в обучающем collator и нулевую `attention_mask`. Изменение padding-токена оказалось численно ненейтральным для полученных моделей. Для точного повторения эта схема сохранена как `legacy_training_padding: true`.

Новые исследования могут отключить этот режим, но после этого все сравниваемые конфигурации следует запускать заново.

## Контроль утечки цели

Целевые токены присутствуют при teacher forcing во время обучения. Перед любой генеративной оценкой и вычислением reward они удаляются функцией `strip_target_tokens`. Тесты и код оценки не используют полный teacher-forced вход.

## Файлы результатов

- `results/paper_results.json`: окончательные числа, перенесённые из статьи;
- `results/raw/classification_main.json`: основная классификационная серия;
- `results/raw/generation_contrast.json`: контрастные генеративные эксперименты;
- `results/raw/generation_reinforce.json`: REINFORCE;
- `results/raw/generation_grpo.json`: GRPO;
- `results/raw/capacity_and_data_sweep.json`: развертка модели и данных;
- `results/raw/*_full_test.json`: переоценка на увеличенных тестовых выборках.

JSON содержит агрегаты и, где применимо, значения отдельных запусков. Адаптеры не включены из-за размера и создаются повторным запуском.
