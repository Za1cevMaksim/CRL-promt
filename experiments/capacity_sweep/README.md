# Размер модели и объём данных

Сценарий повторяет развертку Qwen2.5-0.5B, 1.5B и 3B с выборками от 250 до 6 000 примеров. На каждой точке сравниваются MLE, маска префикса и REINFORCE.

```bash
python experiments/capacity_sweep/run.py
```

Точный список точек и число запусков определены в `main.py`. Результаты сохраняются в `outputs/capacity/`.
