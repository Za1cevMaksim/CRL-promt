# GRPO для генерации ответов

GRPO использует четыре сэмпла на контекст и групповой advantage. Из-за ограничений памяти GRPO-событие заменяет один шаг кросс-энтропии, остальные шаги используют MLE.

```bash
python experiments/grpo/run.py
```

Конфигурация находится в `configs/generation_grpo.yaml`, результаты сохраняются в `outputs/grpo/`.
