# Генерация ответов

Сравниваются MLE, маска префикса, неуместный ответ, переставленный ответ и параметрический REINFORCE на Qwen2.5-3B.

```bash
python experiments/response_generation/run.py
```

Конфигурации находятся в `configs/generation_*.yaml`, результаты сохраняются в `outputs/generation/`.
