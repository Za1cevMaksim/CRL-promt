# Рабочие ноутбуки

Эти файлы сохранены для аудита хода исследования и просмотра исходных логов. Актуальная модульная реализация находится в `src/crl_prompt/`.

| Файл | Назначение |
|---|---|
| `main_experiments.ipynb` | основные эксперименты классификации и генерации |
| `capacity_and_low_data.ipynb` | модели 0.5B–3B, объём данных, репликации и prefix drift |
| `large_test_evaluation.ipynb` | оценка на увеличенных тестовых выборках |
| `grpo_response_generation.ipynb` | GRPO для генерации ответов |
| `paper_figures_and_zero_shot.ipynb` | zero-shot результаты и графики статьи |

Ноутбуки содержат сохранённые выводы. Локальные пути виртуального окружения в них заменены на `<VENV>`.
