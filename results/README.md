# Результаты

`paper_results.json` содержит значения итоговых таблиц статьи и используется командой `python main.py summary`.

Каталог `raw/` содержит агрегированные JSON-файлы завершённых серий. Он не содержит весов моделей и кэша данных. `grpo_reward_history.json` хранит динамику reward, необходимую для повторного построения графика GRPO.

Новые запуски записываются в `outputs/`. Этот каталог исключён из Git, поскольку один адаптер занимает десятки мегабайт.
